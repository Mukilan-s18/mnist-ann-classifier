1. Input Preprocessing

The canvas grid contains 784 pixels ($28 \times 28$). We extract the alpha channel values, scale them between `0` (background) and `1` (brush stroke), and flatten the grid into a $784$-dimensional input vector $\vec{x}$.

2. Hidden Layers (ReLU)

The activations of hidden layer $j$ are calculated by multiplying the weight matrix $W_j$ by the input vector $a_{j-1}$, adding bias vector $\vec{b}_j$, and applying the Rectified Linear Unit (ReLU) function:

a_j = \max(0, W_j \cdot a_{j-1} + b_j)

3. Output Layer (Softmax)

The output layer applies the Softmax function to produce a probability distribution across the 10 classes (digits 0-9):

\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{k=0}^{9} e^{z_k}}
